它是怎么算的

公式全部摊开给你看 —— 而且所有政策参数都能在设置里改，政策变了不用等更新。

// 日薪与秒薪（按当月摊平，所以节假日多的月份日薪自动更高） 日薪 = 税后月薪 ÷ 当月实际计薪天数（按每周工作日 + 节假日/补班日算出） 秒薪 = 日薪 ÷ 每日计薪小时（默认 8） ÷ 3600 // 本月已赚（月底累计正好等于月薪） 本月已赚 = 已过计薪天数 × 日薪 + 今日已工作秒数 × 秒薪 // 五险一金（个人缴纳部分） 缴费基数 = clamp(工资, 基数下限, 基数上限) 个人缴纳 = 缴费基数 × 个人比例 // 例：养老 8%，医疗深圳一档 2%，失业 0.2%，公积金 5%~12% // 个税（累计预扣法，按当前月自动累计） 累计应纳税所得额 = 累计收入 − 5000×月份数 − 累计五险一金 − 累计专项附加扣除 当月个税 = 累计应纳税额 × 预扣率 − 速算扣除数 − 已预扣税额
参数可配置 社保基数上下限、各项比例、公积金比例、7 级税率表、节假日与补班日 —— 全部在「设置 → 政策参数」里，可随时更新。
计算口径 每项险种先各自四舍五入到分再求和（与工资条口径一致）。其他扣款（企业年金等）按税后扣减计入。日薪按当月实际计薪天数摊平，所以节假日多的月份日薪自动更高，月底累计正好等于月薪。
仅供参考 计算结果仅供参考，以实际工资条为准。不同公司申报口径不同，这也是为什么提供五种基数方式。

常见问题

需要安装 .NET 运行时吗？要装什么依赖吗？

都不需要。这是一个自包含的单文件程序，运行环境已经打包进 exe（所以它有 72 MB）。双击就能用，不需要安装任何东西，也不需要管理员权限。

这个软件收费吗？以后会变成收费软件吗？

完全免费：没有广告、没有会员、没有功能限制，也没有打算变成收费软件。

如果它帮到了你，可以在页面下方「请 Lee 老师喝杯咖啡」处随喜支持 —— 不请也完全没关系，你愿意用就是最好的支持。

我的工资数据会被上传吗？

不会。应用不上传任何数据，配置和摸鱼记录都只存在你自己电脑的 %AppData%\SalaryTicker\ 目录里。

唯一的网络请求是「检查新版本」——只 GET 一个几百字节的版本清单，不发送任何你的信息；而且可以在「设置 → 更新」里完全关闭。

怎么卸载？

直接删掉 SalaryTicker.exe 就卸载了（它不写注册表）。如果想连配置一起清掉，再删除 %AppData%\SalaryTicker\ 目录即可。

能自动更新吗？

可以。应用启动后会检查版本，发现新版本时顶部会出现提示条，点「立即更新」即可自动完成下载、校验与重启，不需要重新去网站下载。

能用在其他城市吗？

可以。所有政策参数（基数上下限、比例、税率、节假日）都能在「设置 → 政策参数」里改成你所在城市的值。

后续也计划内置更多城市的参数预设，让它开箱即用。

算出来的数和我工资条对不上？

常见原因是公司申报的缴费基数和实际工资不同。你可以在每个险种下选择「按下限」「按上限」或「自定义基数」，也可以直接从工资条抄数字用「直接填月缴额」。

另外提醒：计算结果仅供参考，请以实际工资条为准。

节假日为什么不计薪？周六补班为什么又计薪？

按 Lee 老师的理念：节假日就该强制休息，不计工资也不计加班费，不鼓励内卷。

而国家规定的「调休补班日」（周末上班的那几天）属于正常工作日，应用会照常计薪。节假日与补班日列表都预置了 2026 年的数据，也可以在设置里自行增删。

数据损坏了怎么办？

配置写入采用「先写临时文件再替换」，并会自动备份最近 10 份。如果配置文件意外损坏，应用会自动回退到最近的备份并在顶部提示，不会崩溃。
