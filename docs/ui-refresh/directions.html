SalaryTicker · UI 方向稿

同一套内容、同一组数据、三种不同的结构。它们不是三套配色，而是三种「钱这件事该怎么被读」的方式。请先看完整版面，再决定方向；也可以指出想混合的轴（颜色 / 字体 / 密度 / 数字呈现）。

A · 暖纸单页 B · 流水台账 C · 浅色专注单板
